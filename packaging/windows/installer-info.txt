Trinix for Windows 10 and 11 (64-bit) - early test version

Share your screen with another device, or see another device's screen on this PC, over your own home or office Wi-Fi. It is free and needs no account.

What Setup does
- Installs Trinix for your Windows account only. Setup does not need administrator rights.
- The first time, it downloads video support. This is a large download, so you need internet and some free disk space.

What Setup does not do
- It does not start sharing. Sharing starts only when you press "Share this screen" in the app.
- It does not change your Windows security settings, add extra display software, or let anyone control this PC.

First use
- Windows may say it "protected your PC", because this early version is not signed yet. If you got Setup from the project, choose "More info", then "Run anyway".
- The first time you share, Windows may ask if Trinix can use your network. Keep "Private networks" ticked and choose "Allow access". Windows may ask for an administrator's password.
- Open Trinix from the Start menu. Help for each step: docs/GETTING_STARTED.md in the project, on GitHub.

To remove it
- Open Windows Settings, then Apps, and uninstall Trinix.
- The video support is a separate program and stays, so other programs can keep using it. You can remove it from the same Apps list if you no longer need it.
