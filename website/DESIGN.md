# Screen-sharing studio

The hero is a precision-device studio composition, with a sculptural green
landscape connecting desktop, laptop and phone. Mode buttons select generated illustrations of mirroring, control and extension. No decorative particle
field, toy device geometry or repeated entrance effects.

Palette: mineral #F5F6F2, white #FFFFFF, evergreen #184C37, leaf #B9E66B,
graphite #24372D. Existing bundled sans-serif typography stays quiet around the
artwork. Centered hero; alternating image/text feature stories; practical release
and alpha status sections below. Direct headline: “Every screen. Within reach.”

Review against brief: replaced the generic homemade device mockups and vague
“make room” slogan with generated studio artwork. The user rejected the floating
window transfer, so it has been removed. The hero now plays a three-chapter scene sequence: a restrained camera move
within each generated composition, a directional wipe into the next mode, and
a synchronized progress rail. Mode buttons select a chapter; Pause freezes both
the camera and chapter clock. Hidden/offscreen scenes pause, and system reduced
motion disables automatic playback. No object moves between device screens.
All assets are local for disk and GitHub Pages use.

Artwork prompts and provenance: `dist/assets/artwork/README.md`.
