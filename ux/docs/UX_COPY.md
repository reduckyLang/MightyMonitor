# Interface copy rules

Use short, direct messages.
Say “this device” and “other device” for device roles.
Give each message one next step.
Keep technical text under Advanced.
Use Copy details for technical text.
Keep default text free of technical terms.

## Testing

`cargo test -p mightymonitor-ux` builds only this crate and `mightymonitor-core`, so it needs no GStreamer development packages.
